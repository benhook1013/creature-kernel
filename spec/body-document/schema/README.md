# Body-document schema

Status: Proposed Readiness 2 candidate; not admitted or activated.

`ck-body-document-v1.schema.json` is the exact Draft 2020-12 structural schema
candidate for the initial strict-UTF-8 JSON body document. It owns shape,
closed members, discriminator recognition, and the Readiness 2 rigid-transform
carrier only. Semantic validity, numeric normalization, graph invariants,
diagnostic vocabulary, and fixture admission remain owned by their respective
specifications and later readiness records.
