# CK-KICK-010 spike package

This Python package contains input [model](model.py)/[resolver](resolver.py),
[diagnostics](diagnostics.py), field and mesh [geometry](geometry.py),
[export](export.py), bundle [artifacts](artifacts.py), the [CLI](cli.py), and
the [module entry point](__main__.py).

Run it through the documented parent [headless-build command](../README.md#headless-build)
from the experiment directory. See the parent [README](../README.md) for the
experiment's scope and interpretation limits.
