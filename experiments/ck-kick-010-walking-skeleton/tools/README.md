# CK-KICK-010 tools

This directory contains helpers for the walking-skeleton workflow:
[reproduce_evidence.py](reproduce_evidence.py) runs the documented valid/invalid
build comparisons, and
[render_semantic_preview.py](render_semantic_preview.py) creates a diagnostic
three-view preview from a mesh and winner-only region sidecar.

Use the documented [evidence reproduction](../README.md#preferred-four-run-evidence-reproduction)
and [semantic preview](../README.md#semantic-diagnostic-preview) commands from
the experiment directory. The commands document their output-path rules.

See the parent [README](../README.md) for the experiment's scope and
interpretation limits.
