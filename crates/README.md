# Crates

This directory contains the members of the Cargo workspace. See each crate's
manifest for package metadata. The active Readiness 1 shell is the
[`creature-kernel-core`](creature-kernel-core/) library and thin
[`creature-kernel-cli`](creature-kernel-cli/) binary; the body-document module
and its tests are the Proposed Readiness 2 parser/bootstrap candidate, not an
admitted or active readiness gate. Normative source meaning remains owned by
[`spec/body-document`](../spec/body-document/README.md), with the exact
candidate schema at
[`ck-body-document-v1.schema.json`](../spec/body-document/schema/ck-body-document-v1.schema.json).
