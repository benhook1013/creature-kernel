# Developer workflows

Status: Active

This directory owns conditional procedures for contributing to Creature Kernel.
The root [contributor instructions](../../AGENTS.md) remain the always-on safety,
authority, and workflow-routing kernel.

Load a workflow only when its trigger applies:

- [AI delegation and review](ai-delegation-and-review.md): subagent selection,
  model routing, delegation boundaries, and independent review.

Workflow documents select process. They do not define product behaviour,
technical architecture, or normative data contracts.
