# Developer workflows

Status: Operational under Accepted DR-0001 Revision 5

This directory owns conditional procedures for contributing to Creature Kernel
under the accepted DR-0001 Revision 5 governance process, with Proposed
DR-0001 Revision 6 transition guidance. Its procedures do not accept or define
product, specification, or architecture contracts. The root
[contributor instructions](../../AGENTS.md) are the lean always-on safety,
authority, and workflow-routing kernel.

Load a workflow only when its trigger applies:

- [AI delegation and review](ai-delegation-and-review.md): subagent selection,
  model routing, delegation boundaries, independent review, PR and external
  review operations, and merge controls.
- [Local visual-review gallery](visual-review-gallery.md): browser-based,
  side-by-side appraisal of generated images through the reusable loopback
  utility.

Workflow documents select process. They do not define product behaviour,
technical architecture, or normative data contracts.
